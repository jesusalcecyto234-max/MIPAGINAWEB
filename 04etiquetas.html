¿Qué son las etiquetas semánticas?

Las etiquetas semánticas en HTML son aquellas que describen el significado del contenido que envuelven. No solo sirven para dar estilo, sino que indican a navegadores, motores de búsqueda y lectores de pantalla cuál es el propósito de cada parte de la página.

Etiqueta <header>

La etiqueta <header> en HTML se utiliza para definir la cabecera de una página o sección. Normalmente contiene elementos como el título, logotipo, menús de navegación o información introductoria relacionada con el contenido.

Ejemplo de uso:

Bienvenido a mi sitio

Inicio | Servicios | Contacto


Etiqueta <section>

La etiqueta <section> en HTML se utiliza para agrupar contenido temático dentro de una página o documento. Cada sección debe tener un propósito claro y normalmente incluye un encabezado (<h1>...<h6>) que describe su contenido.

Ejemplo de uso:

Noticias Recientes

Aquí se muestran las últimas novedades y artículos relacionados.



Etiqueta <article>

La etiqueta <article> en HTML se utiliza para representar contenido independiente y autónomo. Normalmente se emplea para artículos, publicaciones de blog, noticias, comentarios o cualquier bloque de información que pueda existir por sí mismo fuera del contexto de la página.

Ejemplo de uso:

Nuevo lanzamiento de producto

Hoy presentamos nuestra nueva línea de dispositivos inteligentes.



Etiqueta <aside>

La etiqueta <aside> en HTML se utiliza para representar contenido secundario o complementario al contenido principal. Normalmente se emplea para barras laterales, notas, anuncios, enlaces relacionados o información adicional que no forma parte del flujo principal del documento.

Ejemplo de uso:

Enlaces relacionados

  • Artículo sobre HTML
  • Guía de CSS
  • Buenas prácticas de accesibilidad


Etiqueta <footer>

La etiqueta <footer> en HTML se utiliza para definir el pie de página de un documento o sección. Generalmente contiene información adicional como derechos de autor, enlaces de contacto, políticas, créditos o cualquier dato complementario que aparece al final de la página.

Ejemplo de uso:

© 2026 Mi Sitio Web

Contáctanos | Política de Privacidad



Etiqueta <nav>

La etiqueta <nav> en HTML se utiliza para definir una sección de navegación dentro de una página web. Normalmente contiene un conjunto de enlaces que permiten al usuario moverse entre las diferentes partes del sitio o documento.

Ejemplo de uso:

  • Inicio
  • Servicios
  • Contacto


Etiqueta <main>

La etiqueta <main> en HTML se utiliza para representar el contenido principal de un documento o aplicación web. Dentro de <main> se coloca la información más importante y única de la página, excluyendo elementos repetidos como menús de navegación, cabeceras o pies de página.

Ejemplo de uso:

Contenido Principal

Este es el texto central de la página, donde se muestra la información más relevante.

Etiqueta <address>

La etiqueta <address> en HTML se utiliza para definir información de contacto relacionada con el autor o propietario de un documento o artículo. Generalmente incluye direcciones físicas, correos electrónicos, números de teléfono u otros datos de contacto.
